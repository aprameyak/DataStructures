# DataStructures

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white&style=for-the-badge)

## About

**DataStructures** is a Java application that implements and visually demonstrates core data structures from scratch. Built with **Java AWT and Swing**, it pairs each data structure implementation with a dedicated visualizer, letting you watch insertions, deletions, and traversals play out in a graphical UI rather than just reading output in a terminal.

## Features

- Implements 13 data structures from scratch: Graph, Singly Linked List, Doubly Linked List, ArrayList, Binary Tree, AVL Tree, Red-Black Tree, Queue, Stack, Map, Set, Max Heap, and Min Heap
- Dedicated Swing-based visualizer classes for Binary Trees, Heaps, Linked Lists, Queues, and Stacks
- Controller and View classes provide a clean separation between data structure logic and UI rendering
- Each structure supports standard operations including insertion, deletion, and traversal
- Object-oriented design with reusable base components shared across visualizers

## Technology Stack

- **Language**: Java
- **UI**: Java AWT, Swing
- **Build**: Maven
